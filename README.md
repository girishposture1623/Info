# MERN Hotel Booking System (minimal starter)

This repository contains a starter MERN hotel booking system scaffold.

Files created:
- server/ (Express API)
- client/ (Vite + React)
- docker-compose.yml
- .env.example
- README.md

Notes:
- No secrets included. Populate .env per .env.example before running.
- This is a minimal, working scaffold. Expand features as needed.
